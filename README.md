# Mono Chrome — دفتر الشركة

تطبيق حسابات للشركة: منتجات، مبيعات، مشتريات، تحصيلات، مصاريف، وصافي الصندوق بالجنيه المصري.

- المدير يضيف ويعدّل ويحذف
- المشاهد يرى نفس الأرقام ولا يعدّل
- أي حركة تظهر عند باقي أعضاء الشركة
- البيع يخصم من المخزون تلقائياً

السيرفر المنشور: `https://brook-meadow-aurora-sail.grok.me`

## تحميل الـ APK

**[Releases → Mono Chrome — APK](https://github.com/mohammedtaherahmmed-svg/mono-chrome/releases/latest)**

1. حمّل `MonoChrome.apk` وثبّته
2. افتح التطبيق (يفتح السيرفر مباشرة، من غير شاشة رابط)
3. سجّل دخول، أنشئ الشركة كمدير، وادعُ الفريق بكود الدعوة
